# AIZigOS

Микроядерная ОС на чистом Zig с capability-based безопасностью,
семантической ФС и ИИ-шеллом вместо классического рабочего стола.

Это **этап 1**: ядро (раздел 4.1 ТЗ) и capability-подсистема (раздел 4.2).
Файловая система, personality-серверы и браузерный UI-рантайм — следующие
этапы, см. [docs/ROADMAP.md](docs/ROADMAP.md).

## Что уже работает

| Требование | Состояние |
|---|---|
| FR-1.1 планировщик с приоритетами и энергопрофилями | реализовано, 12 тестов |
| FR-1.2 изоляция адресных пространств | реализовано (PMM + VMM + MMU aarch64/x86_64) |
| FR-1.3 IPC sync/async с проверкой capability | реализовано, 8 тестов |
| FR-1.4 HAL с проверяемым контрактом | реализовано, два таргета |
| FR-1.5 бюджет размера ядра | `zig build size-audit`, 144–151 КиБ при бюджете 256 КиБ |
| FR-2.1 доступ только по токену | реализовано |
| FR-2.2 токены с ограничением по времени и области | реализовано |
| FR-2.3 аудит-журнал выдачи/использования/отзыва | реализовано |

Всего 59 модульных и интеграционных тестов, гоняются на хосте без QEMU.

## Сборка

Нужен Zig 0.16.0.

```sh
zig build test                              # тесты ядра на хостовом HAL
zig build -Dboard=virt_aarch64 --release=small   # ядро для QEMU virt (AArch64)
zig build -Dboard=pc_x86_64    --release=small   # ядро для Multiboot2 (x86_64)
zig build size-audit -Dboard=virt_aarch64 --release=small   # аудит бюджета FR-1.5
zig build run -Dboard=virt_aarch64          # запуск в QEMU (нужен qemu-system-aarch64)
```

Бюджет задаётся флагом: `-Dkernel-budget=262144`. Аудит считает загружаемый
образ (.text + .rodata + .data), отдельно показывая .bss — ОЗУ под статические
таблицы ядра — и десять крупнейших символов, чтобы было видно, что съело место.

Проверено: обе цели собираются и проходят аудит. Загрузка в QEMU на этой машине
не проверялась — QEMU не установлен, стартовый код AArch64/x86_64 нуждается в
прогоне на живой машине.

## Структура

```
kernel/
  hal/            HAL: контракт + реализации
    contract.zig  формальный контракт, проверяется на этапе компиляции
    aarch64/      PL011, generic timer, GICv2, MMU, векторы исключений
    x86_64/       COM1, PIT/TSC, IDT+PIC, 4-уровневые таблицы, Multiboot2
    host/         программная реализация для тестов
  mm/             pmm.zig (кадры), vmm.zig (адресные пространства)
  cap/            cap.zig (токены, аттенюация, отзыв), audit.zig (журнал)
  sched/          sched.zig (64 приоритета, 4 класса), power.zig (профили)
  ipc/            эндпоинты, sync/async, делегирование токенов
  proc/           процессы: пространство + владение токенами + потоки
  main.zig        сборка ядра и инициализация
tools/size_audit.zig   аудит бюджета (FR-1.5)
```

Документация: [архитектура](docs/ARCHITECTURE.md), [дорожная карта](docs/ROADMAP.md).
